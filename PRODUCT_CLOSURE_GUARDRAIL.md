# Product Closure Guardrail — Vista composition skill

> Visual polish is a multiplier, never evidence of behavioral completeness.

This repository produces Vista composition artifacts and compatibility payloads. A beautiful HTML file does not prove Campsite persistence, permissions, feed eligibility, publication, correction, withdrawal, revocation, or Stream behavior.

## Local artifact closure

When claiming a Vista render bundle itself is complete, verify as applicable:

- factual content and rendered values use the same source data;
- source/units/baseline/date/uncertainty are preserved where required;
- play/pause/seek/restart or the declared timeline controls work;
- meaningful interaction updates the complete local state consistently;
- interaction can return/reset without corrupting the narrative state;
- reduced-motion and target mobile viewport are handled;
- missing/invalid content fails honestly rather than inventing values;
- the output remains sandbox-compatible and requires no host credentials.

## Host-product boundary

Do not claim any of the following without evidence from the owning Campsite runtime:

- Vista durable identity/revision read-back;
- Camp/Tent persistence;
- Campfire personalization/ranking;
- Trail publish/correct/withdraw/revoke;
- cross-user permissions;
- Stream -> Vista persistence;
- backward compatibility of old links/data.

## Completion receipt

```text
CLOSURE RECEIPT
- Artifact contract verified: ...
```

If a required claim lacks evidence, report **partial / not yet closed**.
